# Coca-Cola Sales Analysis | Power BI

## Project Overview
This project analyzes Coca-Cola sales data using Microsoft Power BI. The report presents sales performance through interactive visualizations to help understand business performance and trends.

## Tools Used
- Microsoft Power BI
- Microsoft Excel / CSV Dataset

## Project Files
- `Coca-Cola-Sales-Analysis.pbix` – Power BI report file.
- `your_dataset.csv` – Dataset used for the analysis.

## Project Objectives
- Analyze sales performance.
- Explore sales and profit trends.
- Present key business information using visualizations.
- Create a dashboard to support data-driven decision-making.

## Key Learnings
- Data visualization using Power BI.
- Working with sales data.
- Presenting business insights through a dashboard.
